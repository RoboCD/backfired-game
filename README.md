# Backfired
This is the repository for the game Backfired, my first game that I made for the Pirate Software Game Jam #16 starting on January 17, 2025.
The theme was *"You are the weapon"*.

## Development
This game was made using Godot as the game engine, Aseprite for the art assets, and free sound and music assets.
The game logic was progamed fully in C++ with GDextension.

### Godot
Made using Godot 4.3 and GDextension to write the logic in C++.

- Branched from template [godot-cpp-template](https://github.com/godotengine/godot-cpp-template)
- [godot-cpp 4.3](https://github.com/godotengine/godot-cpp/tree/4.3)

### Aseprite
All art assets were made using [Aseprite](https://www.aseprite.org/) pixel art editor.
